# Оюутны санал санаачилгын цахим систем

Бакалаврын дипломын ажлын хүрээнд боловсруулсан загвар систем.

Оюутан, багш эсвэл ажилтан санаачилга дэвшүүлж → хамрах бүлгийн гишүүд санал өгч →
босго давбал сургуулийн зөвлөл хугацаатайгаар хариу өгч → дэмжсэн бол хариуцагч
томилогдож хэрэгжилт нь нийтэд мөшгигддөг бүтэн гинжийг хаадаг.

## Ажиллуулах

```bash
npm install
npm run seed
npm run dev
```

`http://localhost:3000` дээр нээгдэнэ.

Демо бүртгэлүүд (нэвтрэх хуудсанд жагсаалттай, нэг удаагийн код дэлгэц дээр харагдана):

| Код | Бүлэг | Эрх |
|---|---|---|
| `B2300001` | Оюутан | Гишүүн |
| `T00001` | Багш | Гишүүн |
| `A00001` | Ажилтан | Гишүүн |
| `M00001` | Оюутан | Модератор |
| `M00002` | Ажилтан | Модератор |
| `C00001` | Багш | Зөвлөлийн гишүүн |
| `C00002`, `C00003` | Ажилтан | Зөвлөлийн гишүүн |
| `S00001` | Ажилтан | Админ |

`npm run seed` нь өгөгдлийн санг **бүрэн устгаад дахин үүсгэнэ**.

## Технологи

| Давхарга | Шийдэл |
|---|---|
| Framework | Next.js 16 (App Router, Server Actions) |
| Хэл | TypeScript |
| Өгөгдлийн сан | SQLite — Node.js 24-ийн дотоод `node:sqlite` модуль |
| Загвар | Tailwind CSS 4 + CSS хувьсагчид (гэрэлт/харанхуй горим) |
| Нэвтрэлт | Оюутны код + нэг удаагийн код, cookie session |

Гадны өгөгдлийн сангийн сервер, ORM, драйвер шаардахгүй — `npm install` хийгээд шууд
ажиллана. Үйлдвэрлэлд гаргах үед `src/lib/db.ts` файлын давхаргыг PostgreSQL руу
солиход л хангалттай (SQL нь стандарт).

## Дизайн — сургуулийн порталтай нийцсэн байдал

Оюутнууд ШУТИС-ийн оюутны порталаас (student.must.edu.mn) энэ систем рүү шилжиж
ордог тул UI/UX-ийг тэр порталын дизайн хэлтэй нийцүүлэв:

| Элемент | Шийдэл |
|---|---|
| Навигаци | Зүүн талын тогтмол sidebar, дүрс + шошготой мөрүүд; гар утсанд хажуугаас гарах цонх |
| Толгой | Дээд мөрөнд мэдэгдэл, сэдэв солих товч, хэрэглэгчийн блок; доор нь хуудасны гарчиг + өнөөдрийн огноо |
| Дэвсгэр | Цайвар цэнхэр (#f2f6fc), карт цагаан, зөөлөн сүүдэр, 14px булангийн радиус |
| Өнгө | Гүн хөх (#174f9f) үндсэн өнгө, алтлаг өргөлт, хар хөх бичвэр |
| Карт | Хажуугийн картын гарчиг төвлөрсөн, доогуураа тусгаарлагчтай |
| Зарын карт | Дугуй аватар + гарчиг + жижиг мета мөр — порталын зарын блоктой ижил бүтэц |
| Товч | Бүтэн дугуй (pill) хэлбэр |
| Sidebar-ын доод хэсэг | Порталын доод мэдээллийн хайрцгуудын хэв маягаар статистик |
| Сэдэв | Гэрэлт / харанхуй горим, localStorage-д хадгална, эхний ачаалалтад анивчихгүй |

Sidebar дэх эмблем нь **түр орлуулагч** — бодит системд сургуулийн албан ёсны логог
`src/components/shell.tsx` доторх `Emblem()` функцэд тавина.

Порталын өнгийг яг тааруулах шаардлагатай бол `src/app/globals.css` доторх `:root`
хэсгийн `--brand`, `--paper` хувьсагчийг солиход хангалттай — бусад бүх хэсэг эдгээр
хувьсагчаас уншина.

> **CSS-ийн анхаарах зүйл:** Tailwind v4-д давхаргад ороогүй (unlayered) CSS нь
> utility классуудыг дардаг. Тиймээс өөрийн хэв маягийг `@layer base` / `@layer
> components` дотор байрлуулсан — эс бөгөөс `lg:hidden`, `w-full` зэрэг ажиллахгүй.

```
    db.ts          node:sqlite холболт, аудит лог

    auth.ts        Нэвтрэлт, эрх, санал өгөх эрхийн шалгалт
    receipt.ts     Саналын баталгааны код (HMAC)
    repo.ts        Хүсэлтүүд + автомат төлөв ахиулагч
    format.ts      Монгол огноо, хугацаа форматлагч
  app/
    page.tsx              Нүүр — жагсаалт, шүүлтүүр, ил тод байдлын үзүүлэлт
    initiatives/new       Санаачилга дэвшүүлэх
    initiatives/[id]      Дэлгэрэнгүй — санал өгөх, хэлэлцүүлэг, шийдвэр
    admin                 Модерацийн дараалал, мэдээлэгдсэн сэтгэгдэл, аудит лог
    council               Зөвлөлийн ажлын самбар, хугацааны хяналт
    journal               Хэрэгжилтийн дэвтэр — хариуцлагын самбар
    policy                Журам (тоонууд нь policy.ts-ээс шууд уншигдана)
    actions.ts            Бүх Server Action
  components/
    shell.tsx             Sidebar + толгой мөр (бүх хуудасны хүрээ)
    icons.tsx             Контур дүрсүүд
    ui.tsx                Server-ээс ашиглагдах харуулах хэсгүүд
    client.tsx            Интерактив маягтууд

```

## Бүлэг, эрх, хамрах бүлэг

Хэрэглэгчийг хоёр тусдаа тэнхлэгээр тодорхойлно:

| Тэнхлэг | Утга | Юуг шийдэх вэ |
|---|---|---|
| Бүлэг (`group_key`) | `STUDENT` · `TEACHER` · `STAFF` | Хэн болох — санал өгөх эрх |
| Эрх (`role`) | `MEMBER` · `MODERATOR` · `COUNCIL` · `ADMIN` | Юу удирдах — модерац, зөвлөлийн шийдвэр |

Иймээс багш нэгэн зэрэг модератор, ажилтан нэгэн зэрэг зөвлөлийн гишүүн байж болно.

Санаачилга бүр **хамрах бүлэг** (`audience`) ба **хүрээ** (`scope`) гэсэн хоёр
шүүлтүүртэй. Санал өгөх эрх нь хоёуланд нь таарах хүнд л олгогдоно.

| Хамрах бүлэг | Оролцох бүлгүүд |
|---|---|
| Бүх нийт (`ALL`) | Оюутан, багш, ажилтан |
| Зөвхөн оюутнууд / багш нар / ажилтнууд | Тухайн ганц бүлэг |
| Багш, ажилтан (`EMPLOYEE`) | Багш, ажилтан |

- Санаачлагч зөвхөн **өөрийн бүлэг багтсан** хамрах бүлгийг сонгоно.
- «Анги, курс» хүрээ зөвхөн оюутан, зөвхөн оюутны хамрах бүлэгт хамаарна.
- Санал өгөх үед бүлэг нь `votes.voter_group`-д хуулбарлагдана — хэрэглэгч устсан ч
  бүлэг тус бүрийн задаргаа өөрчлөгдөхгүй.
- Олон бүлэгт хамаарах санал хураалтын үр дүн хаагдсаны дараа бүлэг тус бүрээр
  нийтлэгдэнэ. Аль нэг бүлгийн цэвэр оноо сөрөг бол зөвлөлийн самбар ба санаачилгын
  хуудсанд анхааруулга гарна (`POLICY.FLAG_OPPOSED_GROUP`).

## Амьдралын мөчлөг

```
Дэмжигч цуглуулж буй  →  Хяналтад  →  Санал хураалт  →  Зөвлөл  →  Хэрэгжиж буй  →  Хэрэгжсэн
        │                    │              │              │
        │                 Буцаасан      Босго дүүрээгүй  Татгалзсан
        │                    │
        └────── засаад дахин илгээх ──┘
```

Төлөв автоматаар ахина — хуудас ачаалагдах бүрд `syncLifecycle()` ажиллаж хугацаа
дууссан санал хураалтыг хааж, эцсийн оноо, одны зэрэглэлийг тогтоож, зөвлөлийн
дараалалд оруулна. Админ гараар товч дарах шаардлагагүй.

| Шийдэл | Эх сурвалж |
|---|---|
| Нийтлэхээс өмнө 3 урьдчилсан дэмжигч шаардах | UK Parliament (5 дэмжигч) — утгагүй санаачилга модератор руу хүрэхгүй |
| Босгыг тохируулагдах параметр болгосон | Decide Madrid 2%→1%, Bundestag 50k→30k буулгасан. Өндөр босго системийг үхүүлдэг |
| Зөвлөл 10 ажлын өдрийн дотор заавал хариулах | «We the People» дундаж 163 хоног хариулж, платформ хаагдсан |

| Таван шатлалт жинлэсэн санал + одны зэрэглэл | Их Британийн оюутны холбоод. Гэхдээ тэдний схемд эсрэг санал ч оноо нэмдэг алдаа байсныг засаж, төвийг тэгд байрлуулсан |
| Хүчтэй дэмжигдсэнийг зөвлөл хориглож чадахгүй | Хууль ёсны байдлын градиент — ★★★★★ дээр хориг хүчингүй |

| Саналын баталгааны код | Санал өгөгч өөрийн санал тоонд орсныг шалгана, гэхдээ сонголт нь ил болохгүй |

## Хамгаалалтын зарчмууд

- Саналын **утга** хаана ч бүртгэгдэхгүй — аудит логт ч орохгүй
- Дэмжлэгийн тоог гараар өөрчлөх зам байхгүй; санал зөвхөн санал өгөгчийн өөрийн үйлдлээр нэмэгдэнэ
- Нэг хүн нэг санаачилгад нэг санал (өгөгдлийн сангийн `UNIQUE` индексээр)
- Хэрэглэгч устгагдсан ч санал `voter_key`-ээр нэргүйжиж үлдэнэ — өнгөрсөн үр дүн өөрчлөгдөхгүй
- Модератор зөвхөн урьдчилан нийтлэгдсэн жагсаалтаас шалтгаан сонгоно
- Бүх удирдлагын үйлдэл аудит логт бүртгэгдэнэ

## Загвар системийн хязгаарлалт

Дипломын хамгаалалт дээр шударгаар дурдах ёстой зүйлс:

- Нэг удаагийн код и-мэйлээр илгээгддэггүй — демо зорилгоор дэлгэц дээр харуулдаг.
  Үйлдвэрлэлд SMTP холбох шаардлагатай.
- Сургуулийн жинхэнэ оюутан, хүний нөөцийн бүртгэлийн системтэй холбогдоогүй; хэрэглэгчийн өгөгдөл
  `scripts/seed.mjs`-ээр үүсгэгдэнэ.
- Зөвлөлийн «2/3-ын саналаар хориглох» дүрэм журамд тодорхойлогдсон боловч зөвлөлийн
  дотоод санал хураалт нь системд хэрэгжээгүй — нэг гишүүн шийдвэрийг бүртгэнэ.
- Мэдэгдэл (и-мэйл, push) байхгүй.
- SQLite нь нэг сервер дээрх ажиллагаанд тохирно. Олон сервертэй орчинд PostgreSQL руу
  шилжүүлнэ.
